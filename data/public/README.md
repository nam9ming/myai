# 여기:it 공개 데이터

사람이 원문·적용 조건·출처·확인 시각을 검토한 데이터의 저장 위치입니다. 현재 실제 공개 공지는 등록하지 않았습니다. 초기 연결용 가상 자료는 `contracts/examples/`에 있습니다.

AI 원출력·개인 평가 기록·비공개 원문·인증정보를 여기에 저장하지 않습니다. 기존 저장·공개 형식은 [계약](../../contracts/README.md)과 [공개 절차](../../backend/docs/review-publication.md)를 따릅니다. 새5분야·신청/진행 일정·자격·비용·미확인 이력은 [데이터 설계](../../docs/spec/03_데이터와AI.md)에 따라 계약 합의·호환 검증 후 적용합니다. 기존 공지나 합성 예시를 시민 대상 새5분야의 검토 완료 자료로 바꾸어 세지 않습니다.
