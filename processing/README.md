# AI·데이터 처리 — 김윤기

현재는 작업 안내만 있습니다. 실제 AI 실행 파이프라인·자료 확보 실적은 없습니다.

1. [작업 범위](TASK.md)를 확인합니다.
2. [데이터·AI 명세](../docs/spec/03_데이터와AI.md)와 contracts의 추출 예제를 사용합니다.
3. 실제 도구/모델·입력 형식·전처리·프롬프트·실행/실패 기록을 구현하면서 문서화합니다.

실제 비공개 처리 자료는 `data/private/`처럼 Git 제외 경로에서 관리합니다. 검토된 공개 결과는 백엔드 담당과 합의한 형식으로 전달합니다.
