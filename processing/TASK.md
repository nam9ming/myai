# 수요일까지: 실제 샘플의 AI 추출과 원문 대조

담당: 김윤기 · 목표일2026-11-04

- 공사·행사·교통 각1건의 개발용 실제 공지부터 구조화합니다. 샘플 확보는 남규민·강명묵과 조율하고 확보하지 못한 자료를 실제 처리했다고 쓰지 않습니다.
- 시작/종료 날짜·시각, 장소, 유형, 적용 대상, 예외와 근거 문장을 추출합니다. 미기재/모호한 값은 null과 이유를 남깁니다.
- 원문 버전·입력/출력 hash·도구 표시명·프롬프트 버전·원출력·실패를 기록합니다.
- AI 원출력과 사람 검토/수정본을 분리합니다. 백엔드에는 검토된 공개 데이터만 전달합니다. 최초 추출 결과는 덮어쓰지 않습니다.
- 지원 도구 접근·이용 조건을 확인합니다. 수동 도구의 결과 파일 import도 가능하며, 새 유료 구매나 API 권한을 확보했다고 가정하지 않습니다.
- 확인용 정답을 프롬프트 개선에 사용하지 않습니다. 실제 샘플과 contracts의 가상 예제를 분리합니다.
- 불필요한 개인 식별정보·연락처와 실제 사용자 평가 기록은 외부 AI 입력에서 제외합니다.

완료 기준: 원문 근거→AI 원래 값→사람 수정값→백엔드 전달 데이터가 추적되고 실제 실행 건수/실패/미완료가 구분됩니다. 먼저 완료하면 백엔드의 시간·거리 예외 검증을 지원해 연결 병목을 줄입니다.
