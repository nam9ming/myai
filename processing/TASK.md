# Python AI·계산 작업

현재 구현: C01~C10·calc-v1·Spring 연결과 [추출 계약 검증·수동 원출력 기록](../contracts/extraction-run.md). 실제 모델/API 실행·개발용 실자료3건·D05 DB 등록·사람 검토본 전달·정답표 평가는 미완료입니다. 아래 전체 요구를 유지하며 합성 시험을 실제 처리 건수로 세지 않습니다.

담당: 김윤기 · 첫 결과: **11/3(화) 오후6시(KST)** · 연구실 시연: **11/4(수), 시각미정**

- Python3.13 가상환경과 의존성을 고정하고 AI 도구의 실제 실행 가능 여부를 확인합니다.
- 남규민이 전달한 공사·행사·교통 개발용 공지 각1건부터 추출합니다. 날짜·시간·장소·대상·예외·근거를 보존하며 미기재/모호 값은 null과 사유를 남깁니다.
- 원문/입출력 hash·도구/모델 표시명·프롬프트 버전·실패를 기록하고 AI 원출력을 덮어쓰지 않습니다.
- 사람 검토·수정본을 공통 D06/D07 형식으로 변환해 강명묵에게 전달합니다. 입력이 가상인지 실제인지 구분합니다.
- [C01~C10](../docs/spec/04_계산규칙과기술설계.md) 순수 Python 계산을 구현하고 [CLI 계약](../contracts/calculation-bridge.md)으로 Spring에 연결합니다. 우선 정상/시간미상/취소와 14일·500m·영업 중첩 경계를 연결하고 나머지 규칙·시험도 전체 계획에 유지합니다.
- CLI stdout은 JSON 한 건, stderr는 비밀정보 없는 진단으로 분리합니다. AI 호출·DB 쓰기·사용자 조건 영구 저장을 계산기에 넣지 않습니다.
- 확인용 정답을 프롬프트 튜닝에 사용하지 않습니다. 개인정보·실제 평가 기록은 외부 AI 입력에서 제외합니다.

오후6시에는 AI 실행·처리 건수·원출력/검토본/전달 JSON, 계산 CLI의 실행 가능한 부분과 미구현 규칙, 설치·실행 명령을 인계합니다. 처리되지 않은 자료나 미실행 시험은 완료로 보고하지 않습니다. 강명묵과 CLI 입출력·버전·오류 연결부터 맞춥니다. [화면 시연 작업 기준](../docs/wednesday-screen-brief.md)도 함께 확인합니다.
