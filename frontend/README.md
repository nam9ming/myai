# 프런트 — 이상헌

현재는 작업 안내만 있습니다. 앱 구현/실행 명령은 아직 없습니다.

1. [작업 범위](TASK.md)를 확인합니다.
2. [화면 명세](../docs/spec/02_화면과모바일UX.md)의 필수 정보·동선을 읽습니다.

4. 실행 가능한 첫 화면이 생기면 설치/개발/빌드 명령과 사용 버전을 이 파일에 추가합니다.

참고 HTML은 `docs/reference/meeting-demo.html`입니다. 동선 참고이며 시각 디자인은 확정되지 않았습니다.
