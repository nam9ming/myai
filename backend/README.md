# 백엔드 — 강명묵

현재는 작업 안내만 있습니다. API 서버는 아직 구현되지 않았습니다.

1. [작업 범위](TASK.md), [API 계약](../contracts/README.md)을 확인합니다.
2. Python/FastAPI를 기본 제안으로 삼아 config/matches/events를 구현합니다.
3. 설치/실행 명령·환경변수 예제·검증 방법은 실제 구현 후 이 파일에 추가합니다.

공유 예제는 `contracts/examples/`에 있으며 실제 공공 공지가 아닙니다. 공개 데이터를 생성할 때 AI 원출력과 사람 검토 결과를 구분합니다.
