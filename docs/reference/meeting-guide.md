# 가게앞 변화알림 안성 — 센터 회의 시연 안내

대상 파일: **가게앞변화알림_안성_센터회의용_v0.2.html**

2026-11-02 작성. 4일 뒤 회의를 고려해 **시연 기준일을2026-11-06으로 고정**했다. 실제 회의 예약이나 공식 공지 날짜를 확인한 결과가 아니다. 현재 화면의 ‘오늘 포함14일’은 이 고정 기준일에서2026-11-19까지다.

## 파일 사용

HTML 한 파일에 CSS·SVG 아이콘·JavaScript·가상 자료가 모두 들어 있다. 별도 설치나 AI/API 연결은 필요하지 않다. 브라우저에서 실행한다. 실제 모바일 카톡 첨부 뷰어에서의 실행은 확인하지 않았으므로, 회의에 사용할 기기에서 파일을 미리 열고 버튼과 원문 새 탭을 확인한다.

브라우저가 탭 저장을 지원하면 조건·유형 필터·팀 검토/공개 상태를 sessionStorage에 보관한다. 차단된 환경에서는 현재 화면 안에서 사용하며, 새로고침 후 복원은 보장되지 않는다. 실제 개인 매출·연락처·사용자 평가 기록을 입력하는 화면은 없다.

## 소개 문구

> 안성 원도심 소상공인이 공사·행사·교통 변경 공지를 가게 위치와 영업시간에 맞춰 확인하는 서비스를 구상했습니다. AI가 공지를 구조화하고, 사람이 근거를 검토한 뒤 시간·거리 조건을 비교하는 방식입니다. 오늘은 실제 데이터 연동 전의 화면 시제품으로 이용 동선과 안내 표현을 보여드리고 의견을 듣고자 합니다. 화면의 공지와 지점은 모두 가상 예시입니다.

## 약3~4분 시연 순서

오른쪽 위 **시연 안내**를 열면 장면을 빠르게 준비할 수 있다. 진행 상태가 남아 있으면 ‘시연 상태 초기화’로 가상 자료만 초기화한다.

| 순서 | 조작 | 설명할 점 |
|---|---|---|
| 1. 가게 조건 | 최초 화면에서 지점 선택 → 시간입력, 또는 ‘일반 영업 예시 채우기’ → ‘관련 공지 보기’ | 가입·매출 입력 없이 시험 지점으로 체험. 요일별/휴무/여러 시간대/야간/미입력도 표현 |
| 2. 관련 공지 | 세유형 필터·정렬, ‘같은 시간에 함께 확인할 변화’ 펼치기 | 단순 가까운 사건이 아니라 기간·영업시간·거리 조건을 대조. 동시 발생 사건도 함께 원문 확인 |
| 3. 적용 조건 | 공사 카드의 ‘조건·근거 보기’ | 원문 사실 / 계산 결과 / 추가 확인할 사항 분리. 대상·예외를 모바일에서도 생략하지 않음 |
| 4. 미상·변경 | ‘확인 필요’ 목록 → 날짜·위치·시간 미상 확인. 시연 안내 ‘정정·취소’ → 종료시각 변경이력. 목록 ‘취소’ 탭 | 모르는 값을 만들어 채우지 않으며 취소된 안내를 유효 후보로 보여주지 않음 |
| 5. 원문 | 카드/상세의 ‘가상 원문’ | 새 탭에서 출처 문서를 확인하는 동선. 가상 원문임을 명시. 원문 연결 실패 예시도 별도로 존재 |
| 6. 팀 검토 | 시연 안내 ‘팀 검토’ → 수정 전 ‘검토 승인’ 클릭 → 오류 확인 → ‘원문에 맞게 수정 예시 적용’ → ‘검토 승인’ → ‘공개 미리보기’ → ‘이 예시를 공개’ | AI 원본은18시, 원문은16시인 예시. 사람 수정값과 원본을 분리하고 승인/공개를 구분. 공개한 가상 카드 확인 |

시간이 짧으면 1→3→4→6을 중심으로 설명한다. 실패/재시도·과거 재현·요일별 편집은 질의 때 보여줄 수 있다.

## 센터에 요청할 의견

- 시범 구역과 기준 지점, 공식 자료원을 어떻게 정하면 적절한지
- 가게 운영자가 날짜·구간·방향·예외를 이해하는 데 빠진 정보가 있는지
- 평가 참여자를 팀이 직접 모집하기 어려워 센터 이용자/기존 프로그램/소상공인 연결 등 협조 가능성이 있는지
- 지원 도구·멘토링·공간/기기·실증 및 제출 일정의 구체 조건

## 구현 범위와 검증

**이번 HTML에서 동작하는 흐름:** 지점/요일별 영업/휴무/시간미상/복수구간/야간/24시간 입력, 공지 유형·정렬, 후보/확인필요/취소, 여러 원인별 확인필요, 중첩시간 묶기, 상세·근거·변경이력, 원문 새 탭, 빈결과/조회실패/재시도, 과거 모드, 브라우저 조건복원, 가상 검토·수정·승인·공개.

**실제 연동 전:** 공식자료 수집·AI 호출·DB/API·Python 시간/거리 모듈·실제 위치/도로 geometry·운영자 접근제어·실제 외부 원문/최신상태 확인·사용자 실증. 공지 등록/AI 처리는 사전에 만든 가상 문서로 시연하며 실제 파일 수집·AI 결과 import 도구를 구현한 것은 아니다. 시연의 거리값은 미리 지정한 값으로, 실측이나 지오코딩 결과가 아니다.

16개 가상 계산/입력 경계 검사를 실행했다. 브라우저에서 초기 검증·후보목록·미상상태·팀 승인차단→수정→승인→공개·원문 새 탭·실패/재시도·뒤로가기/조건복원·과거모드를 확인했다. 390px/320px 크기 시험 프레임의 내부 콘텐츠 폭375px/305px에서 가로 넘침이 없음을 확인했다. 실물 iOS/Android·200% 글자확대·카톡 첨부 실행은 별도 현장 확인이 필요하다. 브라우저 자동화의 보안정책으로 file:// 직접 열기는 검증하지 못해 단일 HTML을 로컬 HTTP로 제공하여 시험했다.

공식 공지40건·개발20/확인20·일치율90%·표시100%·사용자6명 목표/최소3명 평가 추진·시간단축 중앙값20%는 **기존 계획의 목표**이며 이 HTML로 달성했다고 주장하지 않는다. 가상 사건14건과 팀 내부 시연을 실제 공지 확보나 외부 실증으로 세지 않는다.
