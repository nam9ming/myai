### 채택한 시범 대상 — 2026-11-05

[과거 기록·기존 기능 유지] 시범구역은 **안성 동지역 공공시설 생활권**이고 아래5곳을 기준지점으로 채택했다.

- 안성1동 행정복지센터
- 안성2동 주민센터
- 안성3동 행정복지센터
- 안성시청
- 안성시립중앙도서관

행정경계 전체의 확정 polygon을 뜻하지 않는다. 기존 관련성 C06·500m 회귀에서 사용하는 시험용 공공시설이며 참여 점포·시민 모집·상인 실증 실적이 아니다. 시민 전체 탐색의 지역 단계·범위·실제 수집처는 별도 합의한다.

선정만으로 좌표·지명 사전·이용권한 검토를 완료 처리하지 않는다. 미검토 후보는 `unverified`·`active=false`·`checked_by/checked_at=null`을 유지하고 D01 실제 검토 후에만 활성화한다. 원문 사실·관계·사람 승인·공개도 별도다.

### 대조 중 보완한 쟁점

1. 시민 전체 서비스와 기존 소상공인 지점/영업시간·거리 계산 범위를 분리했다.
2. 신청 기간과 진행 일정·모집 마감과 종료·미기재 비용과 무료를 구별했다.
3. 대상·예외·근거·원문·확인 시점과 실제 확보된 변경만 표시하고 자격·변경 전후를 추정하지 않게 했다.
4. 3후보 수용 원칙과 정확한 후보 내용 미제공,4개 AI 제안의 지위를 기록했다.
5. 기존 요구 추적표·회귀와 새 인수표를 분리했다. 동일 사건/연결문서 분할·금표 독립·최초 결과 보존은 유지한다.
6. 별도 관리 UI를 새 필수 인수 조건으로 만들지 않고 S10 동등 보고서·명령을 유지했다.
7. 과거 재현 cutoff·불변 snapshot과 기존/신규 계약의 호환 변경·마이그레이션 경계를 보존했다.

## 팀장이 마지막으로 답하면 되는 질문

1. 우선 분야·실제 수집처·초기 검증 집단과 차별화3후보의 정확한 내용·이번 완료 기준은 무엇인가?
