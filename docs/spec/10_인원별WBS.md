# 10. 4인 WBS·업무분장

갱신일2026-11-17 · 현행 담당: 남규민·김윤기·강명묵·이상헌. 11/16 백엔드 업무지시서와 최신 사용자 결정을 따른다. W01~W15는 [06 실행계획](06_개발실행계획.md)의 추적 ID를 유지한다. 기존 N/B/G/F ID는 작업 자산의 연결을 보존하며 이전 담당을 자동 유지하는 표가 아니다.

## 배분 기준

- **김윤기:** 기존 백엔드 기능 조사→상헌과 화면/API/오류 합의→재사용·변경 개발→연동→명묵 검증 결과의 백엔드 원인 오류 수정.
- **이상헌:** AI/Figma 시안 검토·피드백·화면 확정 후 Flutter Web, 김윤기와 API 연동·화면 오류 조치.
- **강명묵:** 같은 데이터·초기화·환경의 정상/누락/신청마감/진행종료/취소 반복 시나리오 검증·오류 재현·재검증.
- **남규민:** 기획·이번 범위/우선 분야·수집처·개인화·변경 추적·3후보 대응·단계별 일정·자료/평가/운영 조율.

이전 강명묵 백엔드/김윤기 AI 전담 역할은 과거 기록이다. 신규 AI 실행·평가 도구 확장 담당은 현재 변경 범위와 함께 합의하며 역할을 임의 추가하지 않는다. 무룽에게 실제 작업을 배정하지 않는다. 공식 참가 명단과 실제 수행·참석 기록은 구분한다.

각25%는 초기 노력 배분 목표이며 현재 실제 예상/투입 공수·완료율은 확인하지 않았다. 담당자가 예상·실제 시간을 입력하고 구현·검토·자료·회의·실증·문서 시간을 함께 비교한다. 차이가 확인되면 미착수 작업을 인계 단위로 조율한다. 숫자를 만들어 균등·진척을 주장하지 않는다.
