# 10. 4인 WBS·업무분장 v1.2

작성일2026-11-02 · 현재 담당: 남규민·김윤기·강명묵·이상헌. 기존 기술/역할 교환 전 WBS를 대체합니다. W01~W15는 [전체 실행계획](06_개발실행계획.md)의 추적 ID를 유지하고 아래 인원별 작업으로 연결합니다.

## 배분 기준

남규민=자료·통합·연구실 실행·센터/실증/공유, 강명묵=Spring·MySQL·관리/공개 API, 김윤기=Python AI·계산·자동 평가, 이상헌=Flutter Web·디자인·사용자/검토 화면입니다. 무룽에게 실제 작업을 배정하지 않습니다. 공식 참가 명단과 실제 수행·참석 기록은 구분합니다.

각25%는 전체 프로젝트의 초기 노력 배분 목표입니다. 이번 기술 교체 후 실제 예상/투입 시간을 측정하지 않았으므로 동일 공수라고 주장하지 않습니다. 인원별 합계는 구현·검토·자료·회의·실증·문서 시간을 포함해 비교하고, 편차가 확인되면 미착수 작업을 인계 단위로 재배분합니다. 포인트 숫자로 균등을 꾸미지 않습니다.
