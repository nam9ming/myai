# 수요일 화면 시연 작업 기준

기준일: 2026-11-02 · 첫 결과 인계: **11/3(화) 오후 6시(KST)** · 연구실 시연 목표: **11/4(수), 정확한 시각 미정**

## 이번 작업의 완료 모습

연구실에서 제공하는 개발환경에 앱을 올리고 PC 브라우저에서 가게 조건 설정 → 공지 목록 → 상세·근거 → 원문 이동을 직접 시연합니다. 화면은 모바일 우선 반응형으로 구현하며 PC에서도 읽고 조작할 수 있게 합니다. 수요일 필수 확인 범위는 연구실 환경에서의 실행과 시연입니다. 외부 공개 URL·휴대폰 실기기 외부 접속은 후속 확인 항목으로 남깁니다.

교수님이 전달한 요구는 수요일쯤 볼 수 있는 화면을 역할을 나눠 준비하는 것입니다. 이 문서의 세부 화면·연결·인계 기준은 팀의 실행 기준이며 교수님이 모두 직접 지정한 사항으로 표현하지 않습니다.

## 화면 구현 순서

| 순서 | 화면 | 직접 확인할 동작 |
|---|---|---|
| 1 | S02 공지 목록 | 공사·행사·교통, 후보·확인 필요·취소, 제목·기간·위치·상태 표시. 유형 필터와 상세 진입 |
| 2 | S03 공지 상세 | 날짜·장소·적용 대상·예외·근거·원문 링크·확인 시각 표시. 목록 복귀 |
| 3 | S01 가게 조건 | 시험지점 선택, 영업시간 입력·미상 구분, 조건 적용 후 목록 갱신 |

최종 시연 순서는 **S01 → S02 → S03 → 원문**입니다. 목록의 디자인을 조건·상세 화면에 일관되게 적용합니다. 빈 결과·조회 중·조회 실패/재시도도 표시합니다. 없는 날짜·위치·시간을 임의로 채우지 않습니다.

S04 자료·한계 안내는 공통 안내 영역에서 먼저 접근할 수 있게 합니다. S10 팀 검토 도구의 전체 UI와 나머지 명세 항목은 전체 개발 계획에 유지하며 후속 작업을 기록합니다. 수요일에도 AI 원출력의 사람 검토와 미검토 데이터 공개 차단은 유지합니다. 화면이 연결되어도 최종 MVP 인수 기준 전체가 통과된 것으로 보고하지 않습니다.

## 11/3(화) 오후 6시 인계 기준

| 담당 | 코드·파일과 함께 전달할 결과 |
|---|---|
| 이상헌 | 실행 가능한 조건·목록·상세의 첫 버전, 원문 링크와 화면 이동. 공통 예제 JSON으로 전체 동선을 우선 연결하고 디자인 방향을 적용합니다. 캡처와 설치·실행·빌드 명령도 전달합니다. 참고 화면 조사만으로 완료 처리하지 않습니다. |
| 강명묵 | 실행 가능한 FastAPI 서버, config·matches·events 3개 API의 첫 연결 버전. contracts 형식의 예제 데이터로 먼저 응답하고 검토된 데이터의 저장/불러오기 방법을 전달합니다. 미구현 계산·예외는 명시합니다. |
| 김윤기 | 실제 AI 실행 가능 여부, 공사·행사·교통 각 1건부터 추출·검토한 결과. 확보·실행된 건수와 미완료를 구분하고 원출력·검토본·백엔드 전달 JSON 및 실행 방법을 제공합니다. 실제 샘플 미확보가 화면 구현을 막지 않게 공통 가상 예제를 유지합니다. |
| 남규민 | 개발용 공식 공지 샘플 확보·전달, API/파일 형식 교차 확인, 연구실 실행 경로·실행 방법 확인, 각 파트 실행과 첫 통합 점검. 실제 접속 위치와 실행 불가 사유를 기록합니다. |

오후 6시는 첫 결과 취합 시점입니다. 실행 가능한 부분은 준비되는 대로 공유해 프런트↔API와 검토 JSON↔백엔드를 확인합니다. 통합 오류 수정은 취합 후와 수요일에 이어서 진행합니다. 각자 가능한 작업량과 막힌 점을 공유하며 실행하지 않은 기능을 완료로 적지 않습니다.

## 공통 구현·인계 기준

- 기본 환경안: React + TypeScript + Vite / Node.js 24 LTS·npm, Python 3.13 + FastAPI, SQLite·검토된 공개 JSON. 호환 문제는 공유하고 실제 사용 버전과 의존성은 고정해 기록합니다.
- 프런트는 `frontend/`, 백엔드는 `backend/`, AI 처리는 `processing/`을 중심으로 구현합니다. 공통 필드 변경은 관련 담당에게 먼저 공유합니다.
- API·가상 입력/출력은 [contracts](../contracts/README.md)와 [examples](../contracts/examples/)를 사용합니다. 예제는 실제 확보 자료로 집계하지 않습니다.
- 각 폴더 README에 설치·실행 명령, 사용 버전, 환경변수 이름, 데이터 준비 방법, 실제 연동/예제 상태, 미완료를 남깁니다. 프런트 lockfile과 Python의 버전 고정 의존성 파일을 함께 올립니다.
- AI는 수집 자료를 일괄 추출하고 사람이 검토한 결과를 백엔드에 전달합니다. 사용자 조회는 실시간 AI 실행에 의존하지 않습니다.
- 원격 서버의 실행 방식은 남규민이 확인합니다. `/myai/team/`은 장기 경로 후보이며 현재 실행 주소로 단정하지 않습니다. 기존 연구실 운영 서비스 설정은 변경하지 않습니다.

## 수요일 시연 점검

1. 연구실 환경에서 앱을 실행하고 PC 브라우저로 다시 열 수 있습니다. HTML 미리보기와 실제 API 연결 상태를 구분합니다.
2. 조건을 적용하면 목록과 선택 조건 표시가 함께 바뀝니다. 필터·상세·원문·복귀가 동작합니다.
3. 공사·행사·교통, 확인 필요·취소, 대상·예외·근거·확인 시각이 보입니다.
4. 좁은 화면과 PC에서 문구·버튼이 잘리지 않으며 오류가 나도 복구 방법이 보입니다.
5. 실제 자료/가상 예제, API 연결/미연결, AI 실행/미실행, 남은 작업을 명시합니다.

전체 기능·계산 규칙·정량 목표는 [전체 명세](spec/00_목차.md)에 유지합니다. 이번 문서는 수요일까지의 구현 순서와 확인 기준을 정한 문서입니다.
