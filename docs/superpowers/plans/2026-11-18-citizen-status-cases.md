# 시민 공지 상태 재현 계획

기준은 [PR #58](https://github.com/nam9ming/myai/pull/58)이 반영된 `develop` `3cf6626`이다. [Y03·Y10](../../spec/05_시험과인수기준.md#여기it-새-범위-인수)의 원문 상태 보존을 합성 HTTP 사례로 추가한다.

- [x] 기존 5분야 목록·상세의 검증에 신청 마감과 진행 중이 함께 명시된 지원, 취소된 행사, 종료된 공사 사례를 추가했다. 사유가 있는 null도 확인한다. 기존 fixture로는 상태 사례 세 건이 각각 실패했다.
- [x] 합성 원문·근거 위치·해시를 기존 D06 fixture에 함께 반영했다. MySQL 저장·승인·공개를 거친 목록·상세에서 원문 상태 값과 근거를 대조하고 24응답 묶음에 보관한다.
- [x] 변경 5개 파일의 독립 전체 리뷰 1회에서 확인한 주요 지적 1건을 수정했다. 11월 2일 확인 시점에 지원은 신청 마감 후 진행 중이고 공사는 종료를 마친 일정으로 맞췄다. 취소 사례는 당초 일정을 보존한다. 날짜 시험은 수정 전 두 건이 실패했다.
- [x] 최종 MySQL 8.4.13과 실제 JAR를 포함한 Java 시험 60건이 통과했다. 10개 시나리오·24응답·13개 공개본·파일 해시 85개, 5분야 목록·상세의 상태·일정 값 40개와 원문 인용의 위치·해시를 대조했다. 전체 자체 검토에서 유효 미해결 지적은 0건이다.
- [ ] 정확한 PR 소스의 전체 CI·산출물과 실제 리뷰를 검증해 `develop`에 반영하고 작업 브랜치를 정리한다.

이번 합성 자료는 원문 값과 근거를 반복 확인하는 데 쓴다. 실제 화면 연동·팀 인수 증거는 각 담당의 실행으로 남긴다.
